# Catan Strategy Lab — Public Website

This repository serves only the public [Catan Strategy Lab](https://randomquestions-projects.github.io/catan-strategy-lab/) frontend and reviewed aggregate presentation results. The analytical source, datasets, experiments, reproducibility code, and detailed research documentation were moved to the private research repository.

The interactive site needs only `index.html` and the static `assets/` directory. The current browser-only opening simulator and embedded aggregate data remain publicly inspectable; do not store secrets or private algorithm implementations in frontend JavaScript.

Research source files from the former public repository were snapshotted at commit `0b59cf6586266649abb1e344b2efc9ece86c62e1` under `migration_snapshots/catan_2026_11_20/` in the access-controlled research repository, with per-file SHA-256 verification. Historical public commits and cached copies may remain accessible even after this cleanup.

Future updates must export only vetted, rights-cleared, non-sensitive data and UI assets. Never commit original game logs, detailed research datasets, simulation records, credentials, or private models here.

Independent unofficial project, not affiliated with the Catan rights holders.
